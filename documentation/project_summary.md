# Project Summary

## Objective

Analyze food-delivery operations to understand factors associated with delivery time, delivery performance, operational efficiency, and customer experience.

## Dataset

The dataset contains delivery-partner, order-timing, traffic, weather, vehicle, distance, delivery-time, rating, city, festival, and multiple-delivery information.

## Workflow

Business Problem → Data Cleaning → EDA → Feature Engineering → SQL Analysis → Power BI → Insights → Recommendations

## Python

Used for data loading, inspection, missing-value analysis, duplicate checks, outlier analysis, validation, EDA, and feature engineering.

Libraries: Pandas, NumPy, Matplotlib.

## SQL

MySQL analysis covers overall KPIs, delivery performance and speed, traffic, distance, peak periods, time of day, weekday/weekend, vehicle, vehicle condition, multiple deliveries, weather, festival, city, order type, age, ratings, extreme deliveries, combined conditions, CTEs, and window functions.

## Power BI

The Delivery Overview dashboard contains KPI cards, delivery-performance analysis, vehicle comparison, peak vs non-peak analysis, weather, city, and traffic visuals, with filters for City, Vehicle, Traffic, Weather, Time of Day, and Weekend.

## Key Findings

- 38,964 orders are included.
- Average delivery time is approximately 27 minutes.
- Average distance is approximately 9.77 km.
- Average rating is approximately 4.63 / 5.
- Peak periods have higher average delivery time than non-peak periods.
- Heavier traffic is associated with longer delivery times.
- Fog and cloudy conditions show higher average delivery times than sunny conditions.
- Semi-Urban deliveries show substantially higher average delivery time than Urban and Metropolitan deliveries.
- Scooter and electric scooter deliveries show lower average delivery time than motorcycles in this dataset.

## Skills Demonstrated

Python, Pandas, NumPy, Matplotlib, MySQL, SQL, CTEs, window functions, aggregations, Power BI, DAX, dashboarding, KPI analysis, visualization, business problem solving, and operational analytics.

## Outcome

An end-to-end analytics workflow from raw delivery data to SQL analysis, business insights, recommendations, and an interactive Power BI dashboard.
